## A demonstration tailored to the actual rubric

Lead with the teacher's decision, not a list of cloud services: "I have the recording, but the editable project is gone. Keep the explanation and narration; only change a distracting detail if the export proves the preservation contract."

1. Show an original lesson and its explicit preparation changes. Check the smallest teaching label before calling an exact prepared-frame check meaningful.
2. Show the real Blender settings candidate. Protect the settings and let the actual overlap refusal stop the edit. A changing pixel is not automatically an unwanted decoration.
3. Show the disclosed added-corner challenge, protect the teacher/whiteboard, approve the bound recipe and inspect the accepted export and twelve comparison crops. This is the measured positive; never introduce it as naturally occurring damage.
4. Show the unchanged decision record and the two natural-camera recurrence failures. Explain which kinds of recordings the current method cannot repair.
5. Once deployment is verified, identify the AWS task/image/manifest and run the real upload -> OpenCV -> decision -> export flow behind HTTPS. Finish with the precise scope and next real-user experiment. Joseph's real voice remains for the final recording.

This is an evidence-backed route through technical execution (30%), thoughtful vision design (20%), usability (10%), documentation (10%) and responsible cloud operation (10%). The impact criterion (20%) still needs observed creator benefit; source count and test count are not substitutes. The general prize path is appropriate: no unimplemented COOL acceleration or agentic loop should be appended merely to match an optional award.
