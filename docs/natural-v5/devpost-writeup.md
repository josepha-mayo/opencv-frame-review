## Inspiration

**Keep the code. Calm the blink. Keep the cut points honest.**

A teacher has the finished recording, but the editable project is gone. The code is already written; an empty-cell caret keeps blinking through the explanation. We wanted a small editing promise: change the detail the editor chooses, then check that the exported lesson still contains the same teaching pixels, timing and prepared narration.

The first holds removed activity inside the interval but could make the return worse. That became the next problem to solve. The current build chooses source-compatible cut points and refuses an export whose measured entry, return or loop gets worse.

## What it does

Upload a supported lesson or try the real Jupyter, npm or Tamil terminal examples. Inspect both actual observed states. Name the teaching areas that must stay unchanged, check the exact plan, and explicitly generate a comparison. Frame Review holds an observed source state inside one small box and interval. It does not invent replacement imagery.

A caret can explain where typing happens. The editor decides whether its blink can change during a reading pause. Empty or overlapping teaching protection, changed sources, stale approval and failed encoded checks withhold the edited download. The untouched upload, prepared source, recipe, report and decision remain recoverable.

**Try Jupyter in the live AWS app:** protect code/output `[52,96,552,45]` and controls `[50,30,560,60]`. Compare the two states, check the plan and generate. The new plan holds frames 19–97 using observed frame 67. Inspect all twelve boundary crops, the whole-excerpt **24 → 18** result, the encoded cut checks and prepared narration. Download and play the output before deciding whether to use it. No AWS account or app login is needed.

## What we measured

**Seven selected natural-source repairs now complete untouched-original HTTP upload → preparation → reviewed approval → encoded export → exact downloads.** Six repeat prior sources to fix their cuts. One is a newly found Gentoo lesson, tested with the code already frozen. No artificial defect was added.

Across the **same 72 seconds** in the six regression excerpts, selected-region mean RGB changes of at least eight codes fall **90 → 56: 34 fewer, or 37.8%**, including the cuts. There are **zero newly timed threshold crossings**. Per twelve-second excerpt:

- Jupyter notebook: **24 → 18**.
- npm packages: **19 → 13**.
- npm basics: **17 → 11**.
- Make a wikilink: **9 → 3**.
- Adding citations: **6 → 2**.
- Tamil installation: **15 → 9**.

The tradeoff matters. The prior longer holds left 54 changes, but introduced new events in five cases. The new shorter holds leave 56 and introduce none. They hold **17.6 seconds**, versus 24 seconds before. Their interval interiors measure 26 → 0; the old 41 → 0 described different intervals. A lower count alone does not make a good edit.

One fixed spatial-blur reference leaves 91 changes and adds new events in two cases. It is an untuned 5×5 / sigma-2 native-luma Gaussian inside the new box and interval, retaining source chroma. Actual encoded traces, temporal MAE/MSE, local contrast and event times are published. This is not a professional-editor benchmark.

Independent decoders check native samples outside the box, exact held-state mapping, all outside-interval frames, every named teaching RGB sample across all 360 prepared frames, RGB outside the influence area, timestamps and prepared audio or exact absence. Entry, return and loop must each be no worse than source in selected/influence RGB mean absolute, RMS and maximum differences, plus the frozen selected-mean linear diagnostic. The decision includes the encoded measurements.

These are engineering measurements. No creator time saving, attention, comprehension, accessibility, safety, adoption or preference benefit has been measured.

## The new real lesson

In Vitaly Zdanevich’s **Gentoo equery** tutorial, a stationary terminal caret blinks while package progress changes elsewhere. Seconds 62–74 contain the original detail; no corner or animation was added.

The unchanged build proposes box `[370,330,6,10]`, frames 61–173, observed reference 86. The reviewed edit reduces full-excerpt activity **13 → 9**, interior **4 → 0**, with no new events. Commands and the live progress readout stay exact in every frame. All boundary, native and timing gates pass. The source is silent and stays silent.

Its existing entry remains strong: the selected-mean diagnostic is about 0.21815 → 0.21686. Passing no-worsening does not make motion smooth or safe. An editor may reasonably keep the caret. ## How we built it

OpenCV 5 connected components localize temporal support. Native luma/chroma checks establish repeated observed states, dwell, separation and bounded appearance variation. OpenCV generates overlays and checks encoded RGB errors in teaching regions and at the cuts. NumPy represents native samples; FFmpeg handles bounded preparation, export and prepared-audio transport.

The stationary detector remains `steady-proposal-v2`. A separate boundary policy trims at most 30 frames per end and selects among actual observed frames in the originally kept appearance class. It never extends the proposal or blends pixels. The clip’s first and last frames remain unchanged. At least two seconds and four internal changes must remain useful to hold. Approval binds source, analyses, both implementations, exact plan and teaching rectangles; the worker recomputes it before export.

An independent gate measures the encoded result and withholds an export with worse cuts or newly timed events. One integration regression actually encodes the former bad Jupyter hold and confirms its rejection.

**AWS runs the media workflow.** Managed HTTPS reaches an ECS/Fargate task using a digest-pinned ECR image and CloudWatch logs. One bounded worker runs without an application AWS role. Revision 10 completed rollout and verifies all **106 exact runtime files**. All **fourteen Linux qualification stages** pass, including 137 backend unit tests and 84 studio tests (one platform skip). The verification JSON is authoritative; the CLI’s final sentence still has the older word “Thirteen.”

Actual public AWS browser flows for **Jupyter, npm basics and Gentoo** pass original upload, review, approval and downloads. All edited bytes match independent local qualifications, all 36 crop downloads match the reports, completed-job reload works, and the downloaded videos play through twelve seconds at 640×360 without media errors. Gentoo’s actual 375/890 layouts have no horizontal overflow. Known-job reads without the owner cookie return 404. Playback was muted; listening quality was not evaluated.

Codex assisted implementation, experiments, debugging and presentation. No autonomous-agent or COOL award capability is claimed.

## Challenges, limits and next steps

A development Wikilink export hit the unchanged 120 CPU-second cap. Removing redundant decodes brought the final case to about 33.29 CPU seconds. A faster colour-transform optimization changed frozen floating-point results and was rejected. The first full gate hit an unchanged frozen PID-marker test race; a full retry passed. These failures remain alongside the successful receipts.

Intake is capped at 64 MiB and declared supported SDR tracks. Preparation extracts 1–12 seconds, resizes to 640×360/30 fps and prepares optional mono AAC once. It can reduce teaching legibility. Exact edit checks reference the prepared clip; the original stays separate. Teaching rectangles do not track objects. There is no full-lesson splice-back. Jobs are ephemeral, and known multimedia package findings remain.

The impact hypothesis is rescuing a short explanation without rebuilding or re-recording its timeline. Testing that needs consenting educators, preference checks and timed manual-editor comparisons. We have not run those studies.

The current evidence is the live app, the new gallery lead, **six-page report**, exact source ZIP and versioned receipts. The existing 2:46 walkthrough covers an earlier workflow with disclosed neural narration. Joseph’s real-voice recording remains deferred as requested.
