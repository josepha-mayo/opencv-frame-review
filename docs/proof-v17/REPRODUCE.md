It offers 100% (one crop pixel per CSS pixel) and 200% magnification, manual source/edit switching, button/keyboard panning, and closing. Switching versions retains the same scroll coordinates. A new image node starts hidden on every request; dimensions, source-job URL, result identity and render epoch must match before reveal. Stale callbacks cannot reveal the next request. Closing removes the added image. No automatic alternation, video playback, text reconstruction or original-resolution recovery is introduced. Valid teaching cards span the result grid's full row.

The browser checks dimensions; the server verifies source-bound PNG hashes. A hash manifest alone is not independent authentication of the server. The frozen engine, thresholds, boundary renderer and human-study stimuli are unchanged. Three original-source regressions are previously selected French, Joomla and Gentoo lessons; they are not new discovery/held-out recall or human observations.
