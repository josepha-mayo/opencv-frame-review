Choose the explicit action below. Only one candidate can be approved for this job. Retiming repeats one observed cycle and can discard subtle variations; it does not smooth motion. Encoding can change pixels outside the region. The legacy interval hold, if selected, reuses the first sample in each 10-frame block. It changes the animation and can cause an abrupt change when the original frames resume.

Export strategy

5× local retiming inside the detected interval only. Requires at least three repeated cycles, per-plane recurrence mean ≤2 and every sample difference ≤32 native codes. This bounded test can still admit small nonperiodic changes. Strong entry transitions remain; no safety claim.

Protect up to four important areas (optional)

Mark a fixed rectangle containing text, a logo or a counter that should not change. Retiming checks it on every frame against the original source decode; older modes use the unchanged re-encode. This does not track moving content or guarantee preservation. An area overlapping the proposed edit is refused.
